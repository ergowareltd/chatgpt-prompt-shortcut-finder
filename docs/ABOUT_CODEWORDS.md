# What are slash codewords?

In this project, a slash codeword is a short, memorable prompt cue such as `/productshot`, `/roadmap`, or `/cutaway`.

They are not hidden commands built into ChatGPT. A model interprets them from their wording and the surrounding context. The finder therefore works as a searchable prompt vocabulary: it helps you choose a useful shorthand and then combine it with a normal-language request.

Example:

```text
/productshot + /dark-premium premium perfume bottle, black background, side lighting
```

For reliable results, keep the normal-language part of the prompt specific: subject, goal, audience, format, constraints, and desired style all help.
