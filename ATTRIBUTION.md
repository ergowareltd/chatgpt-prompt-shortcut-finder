# Attribution and terminology

Slash Command Finder uses a curated library of user-defined prompt shortcuts.

- 279 visual codeword names were inspired by the public visual codebook shared by John Savage.
- The English descriptions in this repository are independently written summaries for this project; they are not copied from the source PDF.
- Additional shortcuts were collected and developed during the project to cover visual learning, business, marketing, social media, web/UI, writing, and coding use cases.

Source reference:
https://files.johnsavageai.com/ai-pdf-workflows/200-secret-codes-for-chatgpt-expanded.pdf

These codewords are **not official ChatGPT commands** and are not hidden OpenAI features. They are mnemonic prompt labels that a language model can interpret as instructions when sufficient context is provided.
